# Reproduction guide

Run the evidence commands below from the **extracted bundle root**, containing
`code/`, `paper/`, `evidence/` and `supplement.pdf`. They use retained inputs and
do not call a model API. Python 3.11+ is sufficient for the standard-library
checks; figure generation and workbook recalculation additionally need the
dependencies named below.

## Validate the released files and paper numbers

```bash
shasum -a 256 -c MANIFEST.sha256
python3 -m unittest discover -s code/tests -p 'test_paper_*.py'
mkdir -p recomputed
python3 code/scripts/verify_paper_results.py --paper-root paper --output recomputed/numbers.json
```

The numeric verifier checks integer counts, fixed denominators, three-run sample
SD, benchmark-size weighting, per-run token rounding and the retained case-study
and process summaries. `VALIDATION.json` states what was actually tested for this
release. It does not claim that missing historical traces were recovered.

## Recompute the appendix from retained traces

```bash
python3 paper/scripts/analyze_chateval_case_study.py \
  --results evidence/gsm8k/results/gsm8k_chateval_newcore_20260128_144959.json \
  --responses evidence/gsm8k/responses --output recomputed/gsm8k.json

python3 paper/scripts/analyze_jarvis_chateval_incremental.py \
  --archive evidence/gaia/raw/gaia_selected_json_and_logs.tar.gz \
  --responses evidence/gaia/responses --output-dir recomputed/paired

python3 evidence/scripts/compute_gaia_response_stats.py \
  --results-dir evidence/gaia/results --response-dir evidence/gaia/responses \
  --output-csv recomputed/gaia_selected_response_stats.csv

python3 evidence/scripts/compute_gaia_log_stats.py \
  --results-dir evidence/gaia/results --logs-dir evidence/gaia/no-loose-selected-logs \
  --logs-tar evidence/gaia/raw/gaia_selected_json_and_logs.tar.gz \
  --output-csv recomputed/gaia_selected_log_stats.csv

python3 evidence/scripts/compute_gaia_rar_log_stats.py \
  --extracted-dir evidence/gaia/log_rar \
  --batch-csv recomputed/gaia_log_rar_batch_stats.csv \
  --method-csv recomputed/gaia_log_rar_method_stats.csv
```

Expected comparisons are `paper/data/chateval_gsm8k_case_study.json`,
`paper/analysis/jarvis_chateval_incremental/`, and
`paper/analysis/gaia_trace_stats/`. Source paths, input byte hashes and generation
timestamps can differ after redaction; numerical and per-task comparisons remain
the relevant checks. The selected-log CSV reports its retained-response counts
per batch. The appendix's across-level means explicitly use 165 evaluated tasks.

The full bundles also support reconstructing the external CC summaries:

```bash
python3 evidence/cc/scripts/analyze_claude_code_trj.py \
  --input-dir ../raw --output-dir ../../../recomputed/cc
```

This script resolves both arguments relative to its own directory. Compare
`recomputed/cc/per_file_stats.json` with `evidence/cc/derived/per_file_stats.json`.
The size-limited submission retains the CC structured events and derived tables;
its full request dumps are in the separate full companion bundle. Failure
attribution inputs and their method note are in `evidence/attribution/`; they
describe 77/74 localized failures, not all failures in the evaluated split.

## Rebuild tables, figures and PDFs

The editable source is `paper/paper.tex` and `paper/supplement.tex`. With a TeX
installation providing `pdflatex`, `bibtex`, `latexmk` and the class dependencies:

```bash
cd paper
bash scripts/build_paper.sh
cd ..
```

`paper/scripts/calculate_token_avg.py` recalculates the token tables from
`paper/data/token_run_3.xlsx` using `openpyxl`. The plotting scripts in
`paper/scripts/` and `paper/analysis/jarvis_chateval_incremental/plot.py` use
matplotlib; run from the paper directory and inspect their explicit input paths
before replacing existing figures. Current figure assets are already included.
Author-provided count workbooks are in `evidence/author_workbooks/`.

## Run fresh model experiments

Follow `code/README.md`: install its locked Python 3.11/3.12 environment, obtain
the required benchmark files and GAIA attachments under their source terms,
and configure provider credentials locally. `prepare_paper_data.py` validates
processed-file hashes and writes the final 3,302 selected tasks plus indices.
`run_paper.py` prints 210 broad-suite commands by default; `--execute` starts
paid model calls. The published results are retained historical measurements,
not outputs generated by this release preparation.

## Rebuild a full bundle

From an extracted **full** bundle, after reviewing `VALIDATION.json`:

```bash
python3 code/scripts/build_paper_release.py --paper-root paper \
  --materials-manifest MATERIALS.json --validation VALIDATION.json \
  --output-dir rebuilt
```

An anonymous bundle cannot restore removed author metadata. The compact bundle
does not contain the evidence needed to recreate either full bundle.
