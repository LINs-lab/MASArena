# Meeting Notes 2025.04.02

## Summary

The meeting focused on developing a benchmark framework for multi-agent systems (MAS), discussing cost evaluation metrics, benchmark design, and framework implementation. Key areas included cost assessment methodologies, scalability considerations, agent cooperation mechanisms, and framework architecture.

## Key Discussion Points

### 1. Cost Evaluation Framework
- **Measurement Approach**: Combine system cost data with model configurations to calculate comprehensive costs
- **Key Metrics**: Throughput, latency, memory usage, computational costs, and environmental impact (CO2)
- **Aggregation Method**: Need to design a method to aggregate different cost components into a unified score

### 2. Scalability Assessment
- **Definition**: How system performance changes when increasing the number of agents
- **Evaluation Approach**: Test performance across varying task difficulties and hardware constraints
- **Visualization**: Consider graphing performance (y-axis) against number of agents (x-axis)
- **Limitation Detection**: Inability to add more agents indicates scalability boundaries

### 3. Benchmark Design
- **Data Utilization**: Discussed leveraging existing datasets with established workflows
- **Architecture Challenges**: Determining optimal agent quantities, quality levels, and collaboration models
- **Collaboration Models**: Consider agent interactions both with and without user involvement
- **Framework Flexibility**: Design an extensible framework compatible with different MAS methodologies

### 4. System Implementation
- **Interface Design**: Created interfaces for defining both single agents and various agent system architectures
- **Architecture Support**: Implementation supports different paradigms including Supervisor MAS and Swarm
- **Configuration System**: Using TOML files to load model structures and define collaboration relationships
- **Prompt Decoupling**: Need to separate prompts from code and include them as configurable nodes
